# Security Policy

## Supported scope

This repository is currently a public shell for Microcosm. It contains release-boundary and security-intake material plus reserved placeholder paths. It does not contain the private working substrate or a hosted backend service.

In scope:

- this public repository shell
- the public static Microcosm website and same-origin files
- release-boundary claims, source-publication claims, and accidental public fixture/evidence leakage

Out of scope:

- private working environments
- provider accounts, browser sessions, personal devices, or third-party platforms
- social engineering, denial-of-service testing, account targeting, credential guessing, or attempts to access data you do not own

## Reporting

Please use GitHub Private Vulnerability Reporting:

https://github.com/wcook04/microcosm-substrate/security/advisories/new

Do not open public issues for sensitive reports. Issues are disabled on this shell repository so vulnerability details do not get routed into a public channel by accident.

## Expectations

Include the affected URL or reserved source path, the expected versus observed boundary, and a short redacted description. Do not paste suspected secrets, private payloads, raw prompts, session values, or exploit-sensitive details into public channels.

Good-faith reports are welcome. This is not a bug bounty program and the public shell is not permission for intrusive testing.

# Microcosm Substrate

This repository is the public shell for Microcosm.

It exists so public documentation links resolve and security reports have a private intake path. It is not the private `ai_workflow` / Zenith working repository, and it does not publish private source history, raw prompts, operator state, provider/browser state, credentials, private receipts, or internal generated state.

Current release mode:

- `public_shell`: live
- `source_material_population`: withheld or pending
- `private_material_publication`: forbidden
- `full_public_source_release`: not authorized yet
- `security_intake`: GitHub Private Vulnerability Reporting

The file paths in this repository are reserved public source paths. Most bodies are placeholders until a sanitized source-population switch is explicitly cleared.

Security reports: https://github.com/wcook04/microcosm-substrate/security/advisories/new
